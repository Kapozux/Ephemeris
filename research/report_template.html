The storylines, chats and CES-D scores were all generated by us, so this only shows that the pipeline is wired correctly — it says nothing about whether the measures are valid. No correlations, p-values or predictions are reported on purpose.

data_clean.csv uses the input columns of within-person-cesd-screenome (one row per participant × period) and has the columns its build_features requires. Its feature lists are fixed in code, so the chat_ columns have to be added to them (4 lists in 3 files) to be used. evidence.csv lists the messages behind every number, with the verbatim text, the rule-written selection reason and any LLM-generated judgment in separate columns; gold_sample marks rows in the blind re-label sample. chat_features.csv has only chat_-prefixed columns, to merge with Screenome features on pid + period_number.
