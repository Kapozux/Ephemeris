# Ephemeris

[English](README.md) | **中文**

Built by **[Kapozux](https://github.com/Kapozux)**

**把你和 AI 的长期聊天记录变成一份本机的档案，可以用自己的话去问。** Ephemeris 把你在 Claude、ChatGPT、Gemini、Claude Code 等地方的全部对话按天重新整理，而不是按窗口；每天写一篇日记，用一本账本记下你一直在推进的事，再给你一个「问」：像聊天一样问自己的过去，它去翻原始记录再回答。每条结论都附带有时间戳的原话出处，点一下就能跳回那句话。

*ἐφημερίς* 是希腊语的「逐日的记录」，后来被天文学借去指星历表：每天记下天体在哪。这个应用做的是同一件事，记的是你自己。

## 为什么要做

聊天软件按**窗口**存记录：一个对话可以拉好几个月，而一天的事散在十几个窗口里。几个很简单的问题就答不上来：

- 3 月 3 日那天我到底在干什么？
- 这件事我前后弄了多久，上次停在哪？
- 我当时为什么决定这么做？那个想法是我先提的还是 AI 先提的？

Ephemeris 把轴换过来：先把每一天从当天碰过的所有窗口里拼回来，再把一天一天串起来；然后让你直接问。

## 能做什么

### 「问」：问你自己的记录

- **一个全屏聊天页**，照 claude.ai 的样子做：一段对话一个网址，写的时候能停，能同时开好几个问题一起跑。
- **它自己去查，不是凭印象答。** 背后的模型只拿到一个只读的查资料工具：搜原话、搜证据卡、读某一条消息、看某个窗口、看某一天、读手写日记。查几轮、够了才答。
- **每句有依据的话都带出处。** 回答下面列出引用的原话（哪天、哪个窗口、那句话），点「去原话」直接跳到日记页那一天、那一条消息。指向不存在的消息的出处会被删掉。
- **证据卡。** 每个窗口会被做成一张张卡：一句要点 + 一段一字不差抄下来的原话，带上谁说的、哪天、什么话题、哪一类（决定、感受、计划……）。原话会跟原消息逐字核对，对不上的卡直接丢掉，宁可少一张，也不留一张可能是改写或编出来的。卡还有向量，「问」可以按意思找。
- **记忆档案。** 像 Claude 的 memory：「关于你」「你的偏好」加各个领域，每条写明截至哪天、出自哪张卡。每周整理一次；你自己补的条目模型必须留着；不想让它看的页可以关。聊天页菜单里能关掉「用记忆」，那次就只查原始记录。
- **屏蔽。** 选某一天、某个窗口、某篇手写日记，「问」就完全查不到它，连带的卡、日记、档案条目一起挡住。日记页照常显示。
- **也能看电脑上的文件。** 聊天里常提到的日志、文书、PDF，「问」可以只读地打开（只在你允许的文件夹里，默认「文稿」和「下载」；隐藏文件、密钥、数据库一律不看），引用时标「文件」。
- **技能。** 某类问题有专门的做法，写成 `skills/` 下的一页说明，问到这类问题它会自己去读。现在有一个：检验「一条贯穿的线」是真的还是拼出来的（先定标准、按时间抽样报比例、找反例）。
- **回答里可以画图**（图在沙盒里画，不联网）。

公开评测：在 [LoCoMo](https://snap-research.github.io/locomo/)（ACL 2024，1,986 道题，长篇两人对话）上，「问」答对 94%，跟把整段对话直接塞给模型打平；只看证据卡是 64.5%。出处方面，引用的原话能完全撑住回答的是 63%，部分撑住的 28%。

### 日记和回顾

- **每天一篇日记。** 用你自己发出的消息写成，第一人称：这天在忙什么、做完了什么、还有什么没做完。
- **主题账本。** 一件持续的事（一个项目、一份申请、一份作业）会跨天追踪。日记里标着「X 第 23 天」「隔了 41 天又回到 X」。「主题」面板把每条线放在同一条时间轴上看。
- **按窗口回顾。** 挑一个长对话，看它每个活跃日的一句小结，外加整条线的脉络。窗口里接着聊，只补新的天和内容变了的天，旧小结原样保留。
- **也读你手写的日记。** 你自己在 Notion 里写的日期页会被只读地拉进来，放在那天 AI 日记的上面，日历能往前延伸到聊天记录开始之前好几年。Ephemeris 追加进去的内容会先去掉。
- **两个情绪指标，分开记。** 「过得怎么样」来自你自己说的：打卡，或者手写日记。「卡得多狠」（0–4）来自你和 AI 的聊天。实验发现聊天记下的是跟问题较劲的那部分，开心的事多半发生在聊天之外，所以两者从不合成一个数。
- **全屏打卡页。** 点一个词，可以写一句，记下。一天能记好几刻，也能补前几天。每次记完会收到几句回话，它知道你最近在忙什么。月视图有情绪构成比例条、每天一颗星的日历、心情星座和一句话总结。
- **话题河流。** 所有主题归成几个大类，按周画出你的精力在它们之间怎么流动。
- **全文搜索**你发过的所有消息。
- **每天 13:15 自动跑一遍。** 读 Claude Code / Cursor / Codex 的新对话，从 claude.ai 拉新对话，补写缺的日记（今天还没过完，不写），给有新消息的窗口做证据卡。电脑那时在睡觉，醒来后马上补。手动点「立刻同步」走的是同一条流程。
- **它也是你聊天记录的备份。** 只加不删：上游的对话没了、空了，本地都不跟着删；原始导出文件永久留着。同一个窗口存了两份，多的那份挪进存档表，不删。
- **导出。** 单个窗口导成 Markdown，或者整库导出；还有一份「交接包」，把你的背景整理好交给新的 AI 账号。
- **可选同步到 Notion。** 日记写进一个 Notion 数据库。那天你自己已经写过一页，就接在后面写，不动你写的内容。
- **隐私锁。** 可以设一个密码（Mac 上也能用 Touch ID）：页面一切走就锁，服务器也跟着锁。

**日记写一次就定下来。** 新功能都建立在现成的日记上，不会批量重写旧日记。

## 怎么运作

```
claude.ai（每日同步）──┐
Claude Code / Cursor / ├─> index.py ──> chats.db ──┬─> diary.py ──> ledger.py
  Codex（读本机记录）    │   去重、分天     SQLite +   │   每天一篇     把当天的事对到主题上
手动导入 ──────────────┘                 FTS5      ├─> cards.py：证据卡（原话逐字核对）+ 向量
                                                  ├─> memory.py：记忆档案（每周整理）
                                                  └─> qa.py ──> look.py（只读查资料工具）
                                                        「问」     屏蔽的内容在这里滤掉
                                          │
                                          ├─> 网页界面（localhost:5055）
                                          └─> to_notion.py ─> Notion
```

- **一天怎么算**：按 UTC+8，凌晨 4 点才算结束，熬夜聊的归到当天。
- **窗口身份**：用 claude.ai 的对话 uuid。没有稳定 id 的来源，退回用第一条消息算的指纹。
- **每篇日记**都会参考上一篇日记和主题账本，所以能接着昨天往下写。
- **模型读的是**：你自己打的字全部保留；贴进去的材料（文章、代码、字幕、AI 的回答）只留头尾几百字，免得一篇长粘贴把你自己的话挤掉。
- **两种口吻。** 日记和回顾是镜子：做了什么、你说自己感觉怎样，不给建议。打卡的回话是陪伴：具体、站在你这边，有时给一个小建议。
- **把当天的事对到已有主题**，是单独一次很小的模型调用。塞进日记的 prompt 里，主题会越滚越大。「第几天」「隔多久」都由代码来算，模型只做判断。
- **谁说的不靠猜。** 每个平台的导出本来就标着「这条是你发的」还是「AI 回的」，照着记下来；卡上的说话人直接继承那条消息。
- **材料按来源分比例。** 写日记时，AI 聊天占 80%、写代码的工具占 10%、「问」的对话占 10%，免得一天写了很多代码就把别的挤掉。

## 支持导入

- claude.ai：每日自动同步，或者在浏览器控制台运行自带的 `export_claude.js`，导出 JSON / Markdown
- Claude 无痕模式的单窗口 transcript
- Gemini 的 `sess_*.md` 导出
- Google Takeout 里 Gemini Apps 的 `MyActivity.json`
- ChatGPT 官方「导出数据」的 .zip
- DeepSeek 网页（chat.deepseek.com → 设置 → 数据管理 → 导出所有历史对话）的 .zip
- Google AI Studio 导出的 markdown
- 本机的 Claude Code、Cursor、Codex 对话（每天自动读，不用导）
- claude.ai 列表里看不到的窗口（比如无痕窗口）：在「数据来源」贴上它的链接，每天同步时一起拉
- claude.ai 的附件只记名字（「[附件：名字]」），不存内容
- LobeHub 的导出文件

同一份数据导两次也没关系。消息会去重，只有内容真的变了的那几天才会重写日记。

## 安装

需要：一台 Mac 或 Windows 电脑、Python 3.9+、一家模型的 key（DeepSeek / Gemini / OpenRouter / 百炼任选，或者本机装好的 Claude Code）。
Chrome 或 Edge 只有 claude.ai 自动同步要用。

**Mac**

```bash
git clone https://github.com/Kapozux/Ephemeris.git
cd Ephemeris
./run.sh                    # 第一次会自己装需要的东西（一两分钟），然后打开 http://localhost:5055
```

不想开终端：在 Finder 里双击 `启动 Ephemeris.command`（那个窗口别关，关了 Ephemeris 就停了）。

**Windows**

1. 装 Python：从 [python.org](https://www.python.org/downloads/) 下载，安装第一屏一定要勾「Add python.exe to PATH」。
2. 下载这个仓库（GitHub 页面上 Code → Download ZIP，解压到比如 `D:\Ephemeris`；或者 `git clone`）。
3. 双击 `run.bat`。第一次会自己装需要的东西（一两分钟），然后自动打开 http://localhost:5055。
   那个黑色窗口别关，关了 Ephemeris 就停了。以后再双击 `run.bat` 就行。

第一次打开会出「开始用」页：

1. **选一家写日记的模型**，只要那家的 key：
   - **DeepSeek**（只有 DeepSeek 的选这个）：在 [platform.deepseek.com](https://platform.deepseek.com/api_keys) 创建 API key、充一点钱，贴进来。
     写日记、做证据卡、「问」都走它；深挖时它自己调工具翻你的聊天记录。DeepSeek 没有向量模型，「问」按字面找。
   - **Claude Code**：本机装好并登录过 `claude`，不用 key，用订阅额度。
   - **Gemini** / **OpenRouter** / **百炼（通义）**：贴对应的 key。
   key 存之前会先跟那家验一下（不花钱）；错的、没余额的 key 存不进去。
2. 日记里怎么称呼你（可以不填）。
3. **把聊天记录放进来**：直接在这一页选导出文件（DeepSeek / ChatGPT / Claude / Gemini 的 .zip 都行，不用解压），
   或者贴 claude.ai 的 sessionKey 让它每天自动下载。

填的东西只写进本机的 `.env`。弄好之后这一页就不再出现。

`.env` 里的字段（页面上填过的不用再管；用不到的可以不填）：

| 字段 | 用途 |
| --- | --- |
| `EPHEMERIS_PROVIDER` | 用哪家模型：`deepseek` / `claude` / `gemini` / `openrouter` / `dashscope`（「开始用」页选的）。不是 `claude` 就不碰本机的 Claude Code |
| `DEEPSEEK_API_KEY` | DeepSeek 官方 API。`EPHEMERIS_DEEPSEEK_MODEL` 换默认模型（默认 `deepseek-v4-flash`），`EPHEMERIS_CHEAP_PARALLEL` 同时最多几个请求（默认 16） |
| `GEMINI_API_KEY` | Gemini（没有别家时写日记、回顾用；有它时涉政的内容只给它） |
| `DASHSCOPE_API_KEY` | 阿里云百炼（走它上面的 DeepSeek） |
| `EPHEMERIS_UTC_OFFSET` | 你在哪个时区（小时，默认 8） |
| `CLAUDE_SESSION_KEY` | 每日 claude.ai 同步（浏览器里的 cookie）；`CLAUDE_ORG_ID` 可以不填 |
| `DIARY_NAME` | 日记 prompt 里怎么称呼你 |
| `NOTION_TOKEN`、`NOTION_DIARY_DS` | Notion 同步（internal integration secret + 数据库的 data_source_id） |
| `OPENROUTER_API_KEY` | OpenRouter：上面的 DeepSeek / Gemini、证据卡的向量、「设置 → 交接包」 |
| `EPHEMERIS_LLM` | `gemini`（默认）或 `verbatim`（跟着 Verbatim 的模型分流，要把 Verbatim 放在旁边） |

> 所有模型调用都走 `llm.py`：本机 Claude Code 能用就先走它；不然走 DeepSeek（百炼 / 官方 / OpenRouter 轮流），
> 有 Gemini 的话涉政内容只给 Gemini、DeepSeek 失败也回 Gemini；只有 DeepSeek 的话全部给它，限流会自己等一会儿再试。
> 旁边放着 [Verbatim](https://github.com/Kapozux/_Verbatim_) 的 `getAudio/` 的话，key 没填会借它存的，花费也会记进它的账本；没有也完全能用。

只接受本机这个页面发来的请求：别的网站、别的域名指过来的请求一律拒，免得网页偷偷让它同步、写日记、改 key。

## 隐私

所有东西都留在你本机：数据库、日记、打卡、手写日记、导入的文件、Chrome 登录态、`.env`。`.gitignore` 是**白名单**，只有源代码会进仓库。

但它**不是完全离线**：写日记、做证据卡、「问」都要调用模型，用到的那段内容会发给你配置的服务商——写日记发的是某一天*你自己*发出的消息；做卡发的是那个窗口的一段；「问」发的是它查到的那些原话。证据卡的向量走 Google 的 embedding 服务。不想让某些内容出现在「问」里，用屏蔽。

## 成本

- 写日记：用 `gemini-3.5-flash-lite` 大约每天 1 美分（写日记一次调用，匹配主题一次调用）。
- 证据卡：一次导进来很多窗口时自动走便宜的 DeepSeek；平常每天几个窗口。
- 「问」：一个问题要查好几轮，是最花钱的部分。用本机 Claude Code 的话走订阅额度，不另外付钱。
- 会花钱的按钮（补全、立刻同步、Notion 同步）点之前会先问一句，写明范围和大概多少钱。
